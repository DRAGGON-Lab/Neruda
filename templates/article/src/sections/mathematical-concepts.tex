\section{Mathematical model}
The fixed linear map acts on real-valued displacements.
\begin{equation}
  \nerudavector{y} = \nerudamatrix{A}\,\nerudavector{x}.
  \label{eq:scaling}
\end{equation}
\begin{description}
  \item[$\nerudavector{y}$] Output displacement, a real two-component column
    vector with components in centimetres.
  \item[$\nerudamatrix{A}$] Dimensionless \(2\times2\) diagonal matrix.
    Its first diagonal entry is \(2\) and its second is \(1\).
  \item[$\nerudavector{x}$] Input displacement, a real two-component column
    vector with components in centimetres.
\end{description}
