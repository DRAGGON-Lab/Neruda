# Project instructions

This project owns its LaTeX sources under `src/`. Start with the exact
preflight, build and output-check commands in [README.md](README.md).
Select the provisioned TeX Live tree and the pinned native Biber executable
explicitly. Keep shell escape disabled. Tool installation, repair and lock
changes require maintainer approval.

Replace the clearly labeled synthetic example before using the project for
research. Keep metadata, sections or frames, and references in their own files.
Use semantic labels and cite verified sources. Put symbol definitions immediately
after each equation in order of first appearance, reading across and then down.
Explain units, domains and assumptions where relevant.

Inspect the TeX and Biber logs and every PDF page before handoff. For slides,
check the presentation and handout, including the visibility of overlay content.
Keep sensitive research, local build receipts and any private inputs in the
project's authorized storage. Authors approve content and publication.
